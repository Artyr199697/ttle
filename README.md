# 🎯 Avito Master PRO

Профессиональное веб-приложение для управления объявлениями на Avito с системой генерации уникального контента через спинтакс.

![TypeScript](https://img.shields.io/badge/TypeScript-5.2-3178c6.svg)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.3-38bdf8.svg)

## ✨ Основные возможности

### 📦 Управление товарами
- Создание, редактирование и удаление товаров
- Категоризация товаров
- Статистика по каждому товару

### 🎲 Генерация спинтакса
- **Заголовки**: Готовые промпты для Claude AI для создания спинтакса заголовков
- **Описания**: Модульный редактор с блоками описаний
- Предпросмотр всех возможных комбинаций
- Подсчет общего количества вариаций

### 📊 Отслеживание использования
- Автоматическое отслеживание использованных заголовков
- Предотвращение повторений
- История генераций

### 🚀 Массовая генерация
- Генерация до 1000 объявлений за раз
- Уникальные артикулы (10 различных форматов)
- Уникальные ФИО менеджеров (600+ имён, 400+ отчеств, 600+ фамилий)
- Варьирование цен (опционально)

### 💾 Экспорт данных
- **TXT формат**: Готовые объявления с разделителями
- **CSV формат**: Для импорта в таблицы
- **JSON формат**: Для резервного копирования

## 📖 Руководство пользователя

### Этап 1: Создание товара

1. Нажмите **"Добавить товар"**
2. Введите название: например, "ChatGPT Plus"
3. Укажите категорию: например, "Цифровые товары"

### Этап 2: Создание спинтакса заголовка

1. Перейдите на вкладку **"Заголовок"**
2. Скопируйте готовый промт для Claude AI
3. Вставьте название вашего товара в промт
4. Отправьте промт в Claude AI
5. Вставьте полученный спинтакс в приложение
6. Просмотрите примеры и статистику

**Пример спинтакса:**
```
{ChatGPT|GPT} {Plus|+} {месяц|30 дней|1 месяц}
```

Это создаст комбинации типа:
- ChatGPT Plus месяц
- GPT + 30 дней
- ChatGPT Plus 1 месяц
- ...и т.д.

### Этап 3: Создание описания

1. Перейдите на вкладку **"Описание"**
2. Нажмите **"Добавить блок"**
3. Введите оригинальный текст
4. Используйте промт для Claude AI для создания спинтакса
5. Добавьте столько блоков, сколько нужно
6. Управляйте порядком и активностью блоков

### Этап 4: Массовая генерация

1. Перейдите на вкладку **"Генерация"**
2. Укажите количество объявлений (например, 50)
3. Нажмите **"Генерировать"**
4. Получите уникальные объявления с:
   - Уникальными заголовками
   - Уникальными описаниями
   - Уникальными артикулами
   - Уникальными ФИО менеджеров
5. Скачайте в формате TXT или CSV

### Этап 5: Повторная генерация

Через несколько дней:
1. Откройте тот же товар
2. Статистика покажет: использовано 50, доступно 1,200+
3. Сгенерируйте ещё 50 объявлений
4. Получите **новые** заголовки (без повторений!)

## 🎨 Форматы артикулов

Приложение генерирует артикулы в 10 различных форматах:

```
РXX####-РX-####      (РАБ1234-РК-5678)
РX####-РX-####       (РА1234-РК-5678)
РXX####-РXXXX        (РАБ1234-РКДЛ)
РXX##-РXX##-####     (РАБ12-РКД34-5678)
Р######-Р####        (Р123456-Р7890)
РX#X#X#-РX###        (РА1Б2К3-РД456)
РXX-####-XX-####     (РАБ-1234-КД-5678)
Р###X###-Р##X##      (Р123А456-Р78Б90)
РXX####XX-####       (РАБ1234КД-5678)
Р#X#X#X-Р####        (Р1А2Б3К-Р4567)
```

## 💡 Советы и рекомендации

### Создание эффективных спинтаксов

1. **Используйте синонимы**: {купить|приобрести|оформить}
2. **Варьируйте формулировки**: {быстро|моментально|за 5 минут}
3. **Сохраняйте естественность**: Проверяйте все комбинации
4. **Не переусложняйте**: 3-5 вариантов на группу оптимально

### Структура описания

Рекомендуемые блоки:
1. **Вступление** - краткое описание услуги
2. **Основные фичи** - список возможностей
3. **Технические данные** - артикул и менеджер (авто)
4. **Гарантии** - условия и гарантии
5. **Контакты** - способы связи
